# HR Attrition Analysis 👥

## 📌 Project Overview
Analysis of IBM HR dataset to identify key factors driving 
employee attrition using Python and Power BI.

## 📊 Dataset
- Source: IBM HR Analytics Dataset (Kaggle) link: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset/data
- 1,470 employees | 35 columns

## 🔑 Key Findings
- Overall attrition rate: **16.12%**
- Overtime employees leave **3x more** than others
- **Sales department** has highest attrition at 20.63%
- Young employees **(18-25)** have highest attrition at 34%
- Low income employees leave at **3x the rate** of high earners
- Poor work-life balance doubles attrition risk

## 🛠️ Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Power BI Desktop
- SQLite
